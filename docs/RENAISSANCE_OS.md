## CLI usage for future specialist sessions

Run from a clean checkout at the exact desired Git revision. The `--sha` argument is a supplied identity, not a fresh Git attestation; first obtain and verify `git rev-parse HEAD` and compare with current `origin/main`, active PR ownership and intended deployment separately.

```bash
node scripts/renaissance_page_worker.mjs --format queue
node scripts/renaissance_page_worker.mjs --route /kingdom-intelligence --sha "$(git rev-parse HEAD)"
node --experimental-strip-types --test tests/renaissance-page-worker.test.mts
```

Routing aliases are eligible for independent **redirect behavior** testing but not separate page-content worker certification. Queue entries have `PAGE` or `REDIRECT_ALIAS` kinds. Authenticated, admin, parameterized and sensitive templates require a distinct authorized assurance workflow and must not receive public worker packets. A generated assignment never proves GitHub PR exclusivity or production readiness.
