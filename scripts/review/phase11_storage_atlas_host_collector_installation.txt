- Signer is an operator-only host-local agent, with no incoming public HTTP

  and reviewed bounded census, never a web payload.
- Signed UTF-8 JSON must include plane, collector_id, sequence, previous
  receipt digest, source{collector,source_sha}, issued_at, observed_at,
  ttl_seconds, mount_verified, filesystem identity, coherent capacity,
  coverage, census_complete and bounded consumers; never claim measured
  reclaimed bytes from directory estimates. The current #945 verifier
  requires measured_reclaimed_bytes absent/null.
- The exact signed message is UTF8("aoe2war/storage-atlas/receipt-v1\\0")
  with an ACTUAL NUL byte (not backslash text) followed by original
  UTF-8 JSON payload bytes, Ed25519 signature exactly 64 bytes.
  JSON canonicalization for producers and duplicate-field rejection require
  independent implementation and negative tests. The verifier authenticates
  ORIGINAL bytes, not reserialized JSON.
- Issue/observe gap <=30 s, TTL 1..300 s, issued no more than +30 s in
  verifier clock. For independent publisher admission also reject future
  observed_at >publisher_now+30 s; #945 verifier currently checks issued
  future and issued/observation gap but does not directly bound observed_at.
- Sequence is a monotonic nonnegative safe integer per plane, one step per
  publication. A separately durable external witness is mandatory.
- Preserve exact signed bytes, signer key fingerprint, public source SHA,
  host/mount attestation, duration and negative diagnostics in private
  operator evidence. Public page uses redacted aggregate classes only.
