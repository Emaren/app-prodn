PRIVATE CONTRACT aoe2war.storage-atlas.private.v1
- plane exactly mac, hel1-root, hel1-volume-105319120; duplicates invalid.
- filesystem {fs_type, uuid, mount_source, mountpoint}; actual target
  UUID/mount identity must originate from Mac read-only diskutil and HEL1
  findmnt/lsblk/fstab observation, not auto-filled from a page or old map.
- source {collector, source_sha}; observed_at UTC, bounded ttl_seconds.
- capacity {total_bytes, free_blocks_bytes, ordinary_free_bytes}; from real
  statvfs f_blocks, f_bfree, f_bavail and block size, not df Size-Avail
  subtraction. reserved_bytes = f_bfree-f_bavail; used = total-f_bfree;
  effective = used+ordinary_free; effective_percent=used/effective.
  Never treat ext4 reserved blocks as money or ordinary writer capacity.
  APFS snapshots and reclaimable purgeables are NOT a promised reclaimed gain.
- coverage complete/partial/inaccessible; census_complete must be proven by
  all named source probes, partial scan never counted as entire device.
- consumers: exact private paths, measured allocated bytes when known,
  owner and retention classification, rebuild/redundancy/no-live-reference
  evidence and restore dependencies. Each consumer has cleanup_authorized=false.
- proposed_reclaim_bytes is an estimate, independently scoped to same FS;
  measured_reclaimed_bytes remains NULL until a separately authenticated
  pre/post same-device receipt has been validated. A JSON field claiming
  verified=true cannot mint an actual gain.
- growth comparison joins SAME actual filesystem UUID and increasing
  observation time only; unusual >5GiB/day means investigation, not deletion.
- public projection schema aoe2war.storage-atlas.public.v1 exposes only
  anonymous plane, coverage, stale/age, rounded pressure/free bytes, top
  retention classes and severity. It NEVER exports path/owner/UUID/mount,
  source digests, receipt IDs, Wolo settlement data or private credentials.
- if any source inaccessible, stale, unauthenticated, UNKNOWN or partial,
  global admission remains HOLD; browser must never pretend to scan disks.
